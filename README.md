# Sanan Ali — Developer Portfolio

A cinematic, frontier-inspired developer portfolio built around Sanan Ali's real project work, skills, education, active builds, and contact channels. The interface presents the portfolio as an archival field journal with a layered dusk environment, parchment case files, brass details, restrained motion, and an integrated portrait treatment.

## Technologies

- TanStack Start and React 19
- TypeScript and Vite
- Tailwind CSS 4 with a custom CSS design system
- Framer Motion
- Lucide React
- Netlify Forms

## Project Structure

- `src/data/` contains the portfolio's factual content and links.
- `src/components/sections/` contains the homepage sections.
- `src/styles.css` contains the complete responsive art direction and motion system.
- `public/assets/` contains the optimized profile portrait.
- `public/contact.html` enables Netlify's build-time form detection.

## Local Development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

The default development server runs on port `3000`. The production deployment is configured in `netlify.toml`.
